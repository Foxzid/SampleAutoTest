# UI Automation Project: Practice-Automation (C#)

Проект по автоматизации тестирования веб-интерфейса учебного портала [practice-automation.com](https://practice-automation.com) с использованием современных практик QA Automation.

## 🛠 Технологический стек
* **Язык:** C# (.NET 10)
* **Тестовый движок:** NUnit
* **Браузерная автоматизация:** Selenium WebDriver
* **Отчетность:** Allure Report (с автоматическими скриншотами при падениях)

## 📂 Структура репозитория
* `SampleAutoTest/` — основной проект с тестами и логикой взаимодействия.
* `allure-results/` — результаты прогонов (генерируются локально).
* `*.bat` — скрипты для быстрого запуска и очистки среды.

## 🚀 Как запустить тесты
1. Склонируйте репозиторий.
2. Для запуска тестов выполните `Run_Tests.bat`.
3. Для просмотра отчета выполните `Open_Report.bat` (требуется установленный Allure CLI).
